<objective>
Расширить `SuperTextStyle.systemPrompt()` новым опциональным параметром `snippetDictionary: [String: String]`. Когда dictionary непустой, в промпт добавляется инструкция LLM для inline substitution сниппетов — cloud делает грамматически корректную подмену в одном вызове (Option G, D-01).

`CloudLLMClient.processAudio` извлекает snippet словарь из `hints.snippetDictionary` (новое поле в NormalizationHints) и передаёт в systemPrompt. Старый `normalize(...)` путь (Super local) не меняется — там по-прежнему используется snippetContext с placeholder token.

Purpose: Cloud одним round-trip получает аудио и возвращает финальный нормализованный текст с подставленными сниппетами, сохраняя грамматическую корректность. Post-process SnippetEngine.match (Plan 14-04) остаётся safety net.

Output:
- `SuperTextStyle.systemPrompt(snippetDictionary:)` — новый опциональный параметр, дефолт пустой словарь
- Новый блок `ГОЛОСОВЫЕ СОКРАЩЕНИЯ` в промпте (через guard !snippetDictionary.isEmpty)
- `NormalizationHints.snippetDictionary: [String: String]` — новое поле (default [:])
- `CloudLLMClient.processAudio` передаёт `snippetDictionary: hints.snippetDictionary` в systemPrompt
- Unit-тесты: prompt stability без snippets, prompt correctness с snippets, CloudLLMClient wiring
</objective>

## Точный текст нового блока ГОЛОСОВЫЕ СОКРАЩЕНИЯ

Когда `!snippetDictionary.isEmpty`, в конец промпта (ПОСЛЕ styleBlock, ПЕРЕД snippetContext блоком если есть) добавить:

```
ГОЛОСОВЫЕ СОКРАЩЕНИЯ (inline замена):
Пользователь может произнести ключевые слова — замени их в выходном тексте на значения, перестраивая фразу грамматически. Сохраняй значение ДОСЛОВНО (не меняй email, номер телефона, имя). Не добавляй оригинальное ключевое слово рядом с замещённым значением.

Словарь:
<trigger1> → <content1>
<trigger2> → <content2>
...

Примеры применения:
«скинь на мой имейл» → «Скинь на user@example.com»
«привет это мой адрес» → «Привет, это Саша Аминева 9»
«позвони на мой телефон сегодня» → «Позвони на +7 999 123 45 67 сегодня»
```

Where `<triggerN>` / `<contentN>` — entries iterated from snippetDictionary.

## Порядок в systemPrompt:

```
basePrompt
  ↓
styleBlock
  ↓
[КОНТЕКСТ ПРИЛОЖЕНИЯ — если appName]
  ↓
[ПОДСТАНОВКА placeholder — если snippetContext]
  ↓
[ГОЛОСОВЫЕ СОКРАЩЕНИЯ — если !snippetDictionary.isEmpty]   <-- NEW
```

Размещаем в самом конце — ближе к задаче LLM, выше читаемость, меньше риска переопределения стилевым блоком.

    ```swift
    func systemPrompt(
        currentDate: Date,
        personalDictionary: [String: String] = [:],
        snippetContext: SnippetContext? = nil,
        appName: String? = nil,
        snippetDictionary: [String: String] = [:]  // NEW
    ) -> String {
        var prompt = Self.basePrompt(currentDate: currentDate, personalDictionary: personalDictionary)
        prompt += "\n\n" + styleBlock

        if let app = appName, !app.isEmpty {
            prompt += """

            КОНТЕКСТ ПРИЛОЖЕНИЯ:
            Пользователь диктует в приложении «\(app)».
            Учитывай это при выборе тональности и оформления.
            """
        }

        if let snippet = snippetContext {
            prompt += """

            ПОДСТАНОВКА:
            Пользователь использовал голосовое сокращение «\(snippet.trigger)».
            На место этого сокращения вставь РОВНО токен \(SnippetPlaceholder.token) — без кавычек, без изменений.
            НЕ вставляй значение сокращения — только токен.
            Построй естественное предложение вокруг токена.
            Токен должен стоять отдельно, окружённым пробелами или пунктуацией.
            Примеры:
            - "скинь на мой имейл" → "Скинь на мой имейл: \(SnippetPlaceholder.token)"
            - "привет вот мой адрес" → "Привет, мой адрес — \(SnippetPlaceholder.token)."
            - "отправь на мой телефон" → "Отправь на мой телефон: \(SnippetPlaceholder.token)."
            """
        }

        // NEW: inline substitution block для cloud пути
        if !snippetDictionary.isEmpty {
            var block = """


            ГОЛОСОВЫЕ СОКРАЩЕНИЯ (inline замена):
            Пользователь может произнести ключевые слова — замени их в выходном тексте на значения, перестраивая фразу грамматически. Сохраняй значение ДОСЛОВНО (не меняй email, номер телефона, имя). Не добавляй оригинальное ключевое слово рядом с замещённым значением.

            Словарь:
            """
            for (trigger, content) in snippetDictionary {
                block += "\n\(trigger) → \(content)"
            }
            block += """


            Примеры применения:
            «скинь на мой имейл» → «Скинь на user@example.com»
            «привет это мой адрес» → «Привет, это Саша Аминева 9»
            «позвони на мой телефон сегодня» → «Позвони на +7 999 123 45 67 сегодня»
            """
            prompt += block
        }

        return prompt
    }
    ```
