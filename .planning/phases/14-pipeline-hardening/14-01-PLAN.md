<objective>
Добавить новый helper `SnippetReinserter.cleanSubstitute(text:trigger:content:)` — чистая подстановка content вместо trigger БЕЗ префикса `trigger:`. Используется в cloud path (D-04) как fallback когда LLM не выполнил substitution.

Purpose: Отличается от `mechanicalFallback` отсутствием визуального префикса — cloud path не нуждается в диагностическом маркере, output должен быть чистым. mechanicalFallback остаётся нетронутым для Standard fallback поведения (regression-нулевой).

Output:
- Новый static метод `SnippetReinserter.cleanSubstitute(text:trigger:content:) -> String?`
- `triggerRange` сделан internal (было private) для доступа из cleanSubstitute (тот же файл — enum scope, можно оставить private)
- Полные unit-тесты: embedded substitution, word-boundary safety, case/diacritic insensitivity, nil при no-match
- Regression-тесты `mechanicalFallback` сохраняют прежнее поведение с префиксом `trigger:`
</objective>

## Existing mechanicalFallback for comparison (lines 158-191 of PipelineEngine.swift):

```swift
static func mechanicalFallback(
    rawTranscript: String,
    trigger: String,
    content: String
) -> String {
    if let triggerRange = triggerRange(in: rawTranscript, trigger: trigger) {
        let prefix = rawTranscript[..<triggerRange.lowerBound]
            .trimmingCharacters(in: .whitespacesAndNewlines)
        let suffix = rawTranscript[triggerRange.upperBound...]
            .trimmingCharacters(in: .whitespacesAndNewlines)

        var result = ""
        if !prefix.isEmpty {
            result.append(String(prefix))
            result.append(" ")
        }

        result.append("\(trigger): \(content)")  // <-- префикс trigger:

        if !suffix.isEmpty {
            if suffix.first?.isPunctuation == true {
                result.append(String(suffix))
            } else {
                result.append(" ")
                result.append(String(suffix))
            }
        }

        return result.prefix(1).uppercased() + result.dropFirst()
    }

    let capitalizedTrigger = trigger.prefix(1).uppercased() + trigger.dropFirst()
    return "\(capitalizedTrigger): \(content)"
}
```

## cleanSubstitute отличается:
- **Нет** `trigger: ` префикса — вставляется только content
- **Нет** capitalization output (cloud output уже правильно форматирован стилевым блоком)
- **Нет** fallback "\(Trigger): \(content)" при no-match — возвращает nil (вызывающий решает что делать)
- **Нет** trimming — сохраняем исходные пробелы, т.к. cloud output уже чистый

## triggerRange (существующий приватный):
- Word-boundary safe: ищет через NSRegularExpression "\\S+" + token window
- Case/diacritic insensitive (через `.caseInsensitive, .diacriticInsensitive` options)
- Возвращает `Range<String.Index>?` — nil если trigger не найден

    ```swift
    /// Чистая подстановка: заменяет trigger на content БЕЗ 'trigger:' префикса.
    /// Используется в cloud path (D-04) как fallback когда LLM не сделал substitution.
    /// В отличие от mechanicalFallback:
    ///   - нет `trigger: ` префикса — только content
    ///   - нет capitalization — cloud output уже отформатирован стилевым блоком
    ///   - nil при no-match — вызывающий решает что делать
    static func cleanSubstitute(
        text: String,
        trigger: String,
        content: String
    ) -> String? {
        guard !text.isEmpty else { return nil }
        guard let range = triggerRange(in: text, trigger: trigger) else {
            return nil
        }
        return text.replacingCharacters(in: range, with: content)
    }
    ```
