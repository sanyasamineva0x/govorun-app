- Проект уже использует protocol-based DI для всех сервисов (STTClient, LLMClient, CloudAudioProcessing, SnippetMatching) — consistency

- NetworkMonitor уже имеет `isCurrentlyConnected` как sync property — прямой маппинг

Purpose:
- **Тестируемость:** cloud tests в Plan 14-04 используют MockNetworkAvailability для симуляции offline
- **Consistency:** единый стиль с остальными сервисами PipelineEngine
- **Backward compat:** nil default — все существующие 60+ тестов продолжают работать без изменений

<sendable_concern>
## Thread safety / Sendable

- `NetworkAvailabilityProviding: Sendable` — потребует от conformers быть Sendable-safe
- `NetworkMonitor` — `final class` c `@Published private(set) var isConnected`. Уже thread-safe: `isCurrentlyConnected` — pure computed, без mutation. Apple's `NWPathMonitor` sendable через documentation.
- Need: `@unchecked Sendable` on NetworkMonitor OR use protocol без Sendable? Смотрим constraints:
  - `PipelineEngine` хранит `CloudAudioProcessing: Sendable` — current pattern
  - Для консистентности: `NetworkAvailabilityProviding: Sendable`, `extension NetworkMonitor: @unchecked Sendable, NetworkAvailabilityProviding {}` — доверяем что `isCurrentlyConnected` thread-safe (NWPathMonitor.currentPath — documented safe)

ИЛИ проще:
- `NetworkMonitor` становится `final class NetworkMonitor: ObservableObject, NetworkAvailabilityProviding, @unchecked Sendable` — добавляем оба conformance в class declaration
- Это чистый approach

Решение: добавить `NetworkAvailabilityProviding, @unchecked Sendable` в class declaration NetworkMonitor (без отдельного extension). Protocol объявлен Sendable. Mock в тестах — `final class MockNetworkAvailability: NetworkAvailabilityProviding, @unchecked Sendable { ... }`.
</sendable_concern>

    **Шаг 1 — NetworkMonitor.swift:** Добавить протокол (в том же файле) и conformance через class declaration.

    ```swift
    import Combine
    import Network

    // MARK: - NetworkAvailabilityProviding

    protocol NetworkAvailabilityProviding: Sendable {
        var isCurrentlyConnected: Bool { get }
    }

    // MARK: - NetworkMonitor

    final class NetworkMonitor: ObservableObject, NetworkAvailabilityProviding, @unchecked Sendable {
        @Published private(set) var isConnected = false
        private let monitor = NWPathMonitor()

        /// Синхронная проверка через currentPath (не зависит от callback)
        var isCurrentlyConnected: Bool {
            monitor.currentPath.status == .satisfied
        }

        init() {
            // Синхронный snapshot до первого callback
            isConnected = monitor.currentPath.status == .satisfied

            monitor.pathUpdateHandler = { [weak self] path in
                DispatchQueue.main.async {
                    self?.isConnected = path.status == .satisfied
                }
            }
            monitor.start(queue: DispatchQueue(label: "govorun.NetworkMonitor"))
        }

        deinit { monitor.cancel() }
    }
    ```
