<objective>
Интегрировать все Wave 1 компоненты в `processCloudPath` и реализовать offline fallback + snippet + dictionary post-processing.

**Finalized cloud flow (per CONTEXT.md D-09 / D-10 / D-02..D-05):**

```
1. stopRecording() → stopTime, sessionId, snapshotConfig (5-tuple + network)
2. cloud fork detected (productMode.isCloud)
3. processCloudPath invoked:
   a. stop audio, capture audioDurationMs, audioData
   b. Если audioData пустой → return .trivial (existing behaviour)
   c. Cancellation check
   d. NetworkMonitor check: networkAvailability?.isCurrentlyConnected == false
      → offline fallback: call routeToLocalSTTFallback (execute existing standard flow)
      → notify AppState via optional closure onCloudOfflineFallback
   e. Online path:
      i.   Build hints.snippetDictionary from snippetEngine.allTriggerContents()
      ii.  Call cloudClient.processAudio(audioData, superStyle, enrichedHints) → cloudOutput
      iii. DictionaryStore.applyReplacements(to: cloudOutput, replacements: hints.personalDictionary) → dictText
      iv.  SnippetEngine.match(dictText) →
             .standalone → snippetText = match.content
             .embedded  → snippetText = SnippetReinserter.cleanSubstitute(text: dictText, ...)
                          ?? dictText  (cloud inline substitution уже сработал → passthrough)
             nil         → snippetText = dictText
      v.   finalText = applyPostProcessing(snippetText)
      vi.  Return PipelineResult(normalizedText: finalText, normalizationPath: .cloud, rawTranscript: cloudOutput, matchedSnippetTrigger: match?.trigger)
```

**Structural decision — offline fallback:**
Offline fallback маршрутизируется через **извлечённый helper** `processLocalSTTPath(...)` из существующих строк 358-683 stopRecording. Helper принимает те же snapshot-параметры что и processCloudPath. Существующая stopRecording ветка Standard/Super вызывает тот же helper. Таким образом:
- Standard/Super: stopRecording → processLocalSTTPath (тот же код что раньше)
- Cloud online: stopRecording → processCloudPath (online branch)
- Cloud offline: stopRecording → processCloudPath → detects offline → tail-calls processLocalSTTPath

Zero regression guaranteed because non-cloud modes execute same code path через helper.

**D-09a Toast:** PipelineEngine принимает optional callback `onCloudOfflineFallback: (@Sendable () -> Void)?` в init. AppState передаёт closure который вызывает `@MainActor` bottomBar.showError("Нет сети — использую локальную обработку"). PipelineEngine вызывает callback synchronously после detection offline, до routing на local STT.

Purpose: Cloud output полностью проходит post-processing (dict + snippet + list); offline mode не ждёт 30s timeout — мгновенный fallback на локальный pipeline; user получает diagnostic.

Output:
- `processCloudPath` wired: offline-check, dict, snippet (с cleanSubstitute), post-process
- `SnippetMatching` protocol расширен методом `allTriggerContents()`; `SnippetEngine` реализует

- Helper `processLocalSTTPath` — извлечён из существующего stopRecording тела (строки 358-683), вызывается из обоих fork-ов
- `AppState` wires callback → `bottomBar.showError` на @MainActor
- Новые integration тесты: offline fallback, snippet dictionary injection, snippet match после cloud output, dictionary replacement после cloud output, regression всех 10 existing cloud tests

```swift
func stopRecording() async throws -> PipelineResult {
    let stopTime = CFAbsoluteTimeGetCurrent()
    let sessionId = snapshotSessionId()
    let (currentProductMode, currentSuperStyle, currentHints, currentLLMClient, currentCloudClient) = snapshotConfig()
    let currentNetwork = currentNetworkAvailability()
    let effectiveTerminalPeriod = currentSuperStyle?.terminalPeriod ?? terminalPeriodEnabled

    func applyPostProcessing(_ text: String) -> String {
        let periodText = effectiveTerminalPeriod
            ? text
            : DeterministicNormalizer.stripTrailingPeriods(text)
        let styledText = currentSuperStyle?.applyDeterministic(periodText) ?? periodText
        return ListFormatter.format(styledText, style: currentSuperStyle)
    }

    if currentProductMode.isCloud {
        return try await processCloudPath(
            stopTime: stopTime,
            sessionId: sessionId,
            superStyle: currentSuperStyle,
            hints: currentHints,
            cloudClient: currentCloudClient,
            networkAvailability: currentNetwork,
            productMode: currentProductMode,
            llmClient: currentLLMClient,
            applyPostProcessing: applyPostProcessing
        )
    }

    return try await processLocalSTTPath(
        stopTime: stopTime,
        sessionId: sessionId,
        superStyle: currentSuperStyle,
        hints: currentHints,
        llmClient: currentLLMClient,
        productMode: currentProductMode,
        applyPostProcessing: applyPostProcessing
    )
}
```

<offline_fallback_productMode>
## Important: какой productMode передавать в offline fallback

Per CONTEXT.md D-09: offline fallback = "routing в существующий local STT flow (как в Standard режиме)". Cloud mode при offline НЕ пытается использовать local llama-server. Значит:

`processLocalSTTPath(productMode: .standard)` — когда вызывается из offline-cloud fallback.

Это означает: LLM не вызывается (usesLLM=false для .standard), text проходит через deterministic path → trivial → applyPostProcessing. Корректно для cloud→offline graceful degradation.

    private func processCloudPath(
        stopTime: CFAbsoluteTime,
        sessionId: UUID,
        superStyle: SuperTextStyle?,
        hints: NormalizationHints,
        cloudClient: CloudAudioProcessing?,
        networkAvailability: NetworkAvailabilityProviding?,
        llmClient: LLMClient,
        applyPostProcessing: (String) -> String
    ) async throws -> PipelineResult {
        // Offline fast-fail (D-09): delegate to local STT path as .standard
        if let network = networkAvailability, !network.isCurrentlyConnected {
            onCloudOfflineFallback?()
            Self.logger.info("Cloud mode offline — routing to local STT fallback")
            return try await processLocalSTTPath(
                stopTime: stopTime,
                sessionId: sessionId,
                superStyle: superStyle,
                hints: hints,
                llmClient: llmClient,
                productMode: .standard,
                applyPostProcessing: applyPostProcessing
            )
        }

        markRecordingStopped()
        let audioDurationMs = Int(audioCapture.duration * 1_000)
        let audioData = audioCapture.stopRecording()

        // Сохраняем аудио на диск для истории
        let audioFileName: String?
        if !audioData.isEmpty, saveAudioHistory {
            do {
                audioFileName = try saveAudioFile(audioData, sessionId)
            } catch {
                Self.logger.error("Failed to save audio history: \(String(describing: error), privacy: .public)")
                audioFileName = nil
            }
        } else {
            audioFileName = nil
        }

        func cleanupAudioOnFailure() {
            if let audioFileName { deleteAudioFile(audioFileName) }
        }

        // Пустое аудио → trivial
        guard !audioData.isEmpty else {
            let totalMs = Int((CFAbsoluteTimeGetCurrent() - stopTime) * 1_000)
            return PipelineResult(
                sessionId: sessionId,
                rawTranscript: "",
                normalizedText: "",
                superStyle: superStyle,
                normalizationPath: .trivial,
                sttLatencyMs: 0,
                llmLatencyMs: 0,
                insertionLatencyMs: 0,
                totalLatencyMs: totalMs,
                audioDurationMs: audioDurationMs,
                audioFileName: audioFileName
            )
        }

        guard !currentIsCancelled() else {
            cleanupAudioOnFailure()
            throw PipelineError.cancelled
        }

        // Enrich hints with snippet dictionary (D-01 Option G)
        let snippetDictionary = snippetEngine?.allTriggerContents() ?? [:]
        let enrichedHints = NormalizationHints(
            personalDictionary: hints.personalDictionary,
            appName: hints.appName,
            currentDate: hints.currentDate,
            snippetContext: hints.snippetContext,
            snippetDictionary: snippetDictionary
        )

        // Cloud API
        let llmStart = CFAbsoluteTimeGetCurrent()
        let cloudOutput: String
        let llmLatencyMs: Int

        do {
            guard let cloudClient else {
                throw LLMError.networkError("Cloud client не настроен")
            }
            cloudOutput = try await cloudClient.processAudio(
                audioData: audioData,
                superStyle: superStyle ?? .normal,
                hints: enrichedHints
            )
            guard !currentIsCancelled() else {
                cleanupAudioOnFailure()
                throw PipelineError.cancelled
            }
            llmLatencyMs = Int((CFAbsoluteTimeGetCurrent() - llmStart) * 1_000)
        } catch PipelineError.cancelled {
            cleanupAudioOnFailure()
            throw PipelineError.cancelled
        } catch is CancellationError {
            cleanupAudioOnFailure()
            throw PipelineError.cancelled
        } catch {
            llmLatencyMs = Int((CFAbsoluteTimeGetCurrent() - llmStart) * 1_000)
            Self.logger.error("Cloud API failed: \(String(describing: error), privacy: .public)")
            cleanupAudioOnFailure()
            let totalMs = Int((CFAbsoluteTimeGetCurrent() - stopTime) * 1_000)
            return PipelineResult(
                sessionId: sessionId,
                rawTranscript: "",
                normalizedText: "",
                superStyle: superStyle,
                normalizationPath: .cloudFailed,
                sttLatencyMs: 0,
                llmLatencyMs: llmLatencyMs,
                insertionLatencyMs: 0,
                totalLatencyMs: totalMs,
                audioDurationMs: audioDurationMs,
                audioFileName: nil
            )
        }

        // Post-cloud: Dictionary → Snippet → applyPostProcessing (D-05, D-10)
        let dictText = DictionaryStore.applyReplacements(
            to: cloudOutput,
            replacements: hints.personalDictionary
        )

        let snippetText: String
        var matchedSnippetTrigger: String?

        if let snippetEngine, let match = snippetEngine.match(dictText) {
            matchedSnippetTrigger = match.trigger
            switch match.kind {
            case .standalone:
                // D-03: литеральная замена всего текста на content
                snippetText = match.content
            case .embedded:
                // D-04: cleanSubstitute; если nil — cloud уже сделал substitution inline
                snippetText = SnippetReinserter.cleanSubstitute(
                    text: dictText,
                    trigger: match.trigger,
                    content: match.content
                ) ?? dictText
            }
        } else {
            snippetText = dictText
        }

        let finalText = applyPostProcessing(snippetText)
        let totalMs = Int((CFAbsoluteTimeGetCurrent() - stopTime) * 1_000)
        return PipelineResult(
            sessionId: sessionId,
            rawTranscript: cloudOutput,
            normalizedText: finalText,
            superStyle: superStyle,
            normalizationPath: .cloud,
            sttLatencyMs: 0,
            llmLatencyMs: llmLatencyMs,
            insertionLatencyMs: 0,
            totalLatencyMs: totalMs,
            matchedSnippetTrigger: matchedSnippetTrigger,
            audioDurationMs: audioDurationMs,
            audioFileName: audioFileName
        )
    }
